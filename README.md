# Bloodbound Ascendants

Create a multiplayer browser-based RPG called The Bloodbound Ascendants.

The game should be inspired by tabletop RPGs, dungeon-crawling adventures, and narrative-driven progression systems.

Core Concept

Players create unique characters known as Bloodbound Ascendants.

Every character possesses:

A Race (Bloodline)

An Aspect (Class)

Resonance Traits

Weaknesses

Vital Measures

Ascension Tiers

The game should focus on exploration, dungeon raids, character growth, difficult choices, teamwork, and narrative consequences.

Combat should combine dice rolls, character stats, abilities, and dungeon mechanics.
